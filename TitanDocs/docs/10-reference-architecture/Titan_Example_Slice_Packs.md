# Titan Example Slice Packs

Provides short examples of what a bounded slice pack should contain.

## Example — jobs.execution

Includes:
- ServiceJob
- Visit
- Checklist
- ProofOfService
- visit lifecycle states
- assignment tools
- proof rules
- review triggers

Excludes:
- payroll
- social campaigns
- admin package registry

## Example — finance.recovery

Includes:
- Invoice
- Payment
- consent rules
- channel delivery states
- follow-up policy
- review queue examples

Excludes:
- job dispatch
- social assets
- package rollout

## Example — comms.inbox

Includes:
- Thread
- Message
- participant identity
- consent record
- delivery states
- fallback rules
- reply approval examples

Excludes:
- invoice settlement logic
- route optimization
- module rollout
