# Titan Spec Template Library

Provides reusable templates for writing future Titan docs consistently.

## Template 1 — Object Pack

- Purpose
- Core Fields
- Relationships
- Lifecycle or states
- Required guards
- Suggested tables
- Example signals

## Template 2 — Mode Spec

- Purpose
- Core objects
- Core surfaces
- Key signals
- Constraints
- Suggested actions
- Required guards
- Suggested tables

## Template 3 — Example Doc

- Purpose
- Example 1
- Example 2
- Example 3
- Required fields
- Notes

## Template 4 — Policy Spec

- Purpose
- Inputs
- Decision logic
- Outputs
- Required reason codes
- Suggested tables

## Template 5 — Mapping Guide

- Purpose
- Canonical object map
- Family prefixes
- Support columns
- Exceptions
- Migration notes

## Writing Rules

- keep headings short
- keep terms canonical
- include bounded examples
- separate rules from examples
- name tables consistently
